# 自動化設定教學（第 3 階段）

全部在 iPhone 上做。每一步都有「成功時會看到什麼」，對不上就停下來截圖回報。

> 動作名稱是照 iOS 繁體中文介面寫的，括號裡是英文名稱。iOS 版本不同，名稱可能略有差異；找不到時在動作搜尋框打英文名稱試試。

需要先完成：雲端同步已登入、照片伺服器網址已填（第 2 階段做好的）。

---

## A. 準備（只要做一次）

### A1. 在 Supabase 執行設定 SQL

1. 開記帳日記 App →「統計」分頁 → 往下找到「自動化」→ 按「複製設定 SQL」。
2. 用 Safari 開 Supabase 後台 → 你的專案 → 左側「SQL Editor」→「New query」。
3. 在編輯區長按 →「貼上」→ 按「Run」。

**成功時**：下方顯示 `Success. No rows returned`。

### A2. 產生自動化金鑰

1. 回到 App 的「自動化」→ 按「產生自動化金鑰」。
2. 按「測試連線」。

**成功時**：顯示「連線正常：ok（時區 Asia/Taipei）」。

- 顯示「還沒建立自動化用的資料表」→ A1 沒有成功，再做一次。
- 顯示「照片伺服器還沒更新到有自動化功能的版本」→ 照片伺服器還在部署，過幾分鐘再試。

金鑰等同密碼：不要截圖給別人。外流的話按「重新產生金鑰」，舊的立刻失效（Overland、捷徑、小工具都要換新的）。

## B. 背景定位（Overland）

1. App Store 搜尋「Overland GPS Tracker」（開發者 Aaron Parecki，免費）→ 安裝 → 打開一次，允許通知。
2. 回到記帳日記「自動化」→ 展開「③ 背景定位」→ 按「一鍵設定 Overland」→ 問要不要打開 Overland 時按「打開」。
3. Overland 會自動填好接收網址（Receiver Endpoint）和金鑰（Access Token）。
4. 在 Overland 開始追蹤，定位權限選「永遠（Always）」。

**成功時**：過幾分鐘後（Overland 會一批一批送），回到記帳日記，地圖上出現今天的路線；待在同一個地方超過 10 分鐘，時間軸會出現灰色的「抵達 ○○」「離開 ○○」。

設定建議（省電優先）：送出間隔（Send Interval）設 5～15 分鐘就好，不需要每秒送。
Overland 的設定畫面名稱我無法在開發環境確認，找不到對應的選項就先用預設值，告訴我你看到的畫面。

備案：改用 OwnTracks 的話，模式選 HTTP，網址用「複製 OwnTracks 網址」貼上（網址已含金鑰）。

## C. 捷徑

先到 App「自動化」→ 展開「④ 捷徑」，等一下要貼的東西都從這裡複製：
- **授權**：`Bearer ld_…` 整串
- **記一筆網址**、**步數網址**、**記下位置網址**

每個「取得 URL 內容」動作都要這樣設定（後面不再重複）：
1. 網址欄：貼上對應的網址
2. 點「顯示更多」：方法（Method）選 **POST**
3. 標頭（Headers）→ 加入新標頭：鍵 `Authorization`，值貼上「授權」（開頭要是 `Bearer ` 加一個空格）。**不要留空白的標頭**，多出來的空行要按紅色「－」刪掉，否則會出現「網路連線中斷」
4. 要求本文（Request Body）選 **JSON**，再依各捷徑的說明加入欄位

### C1. 快速記一筆

捷徑 App →「捷徑」分頁 → 右上「＋」→ 名稱改成「記一筆」，依序加入動作：

1. **要求輸入**（Ask for Input）：類型「數字」，提示「金額」
2. **列表**（List）：項目依序填 餐飲、交通、購物、住宿、門票、日用、娛樂、帳單、醫療、其他
3. **從列表中選擇**（Choose from List）：提示「分類」
4. **要求輸入**：類型「文字」，提示「一句話」
5. **取得目前位置**（Get Current Location）
6. **取得 URL 內容**（Get Contents of URL）：用「記一筆網址」，JSON 欄位：

   | 鍵 | 類型 | 值（點值的欄位 → 選變數） |
   |---|---|---|
   | amount | 數字 | 第 1 步的「提供的輸入」 |
   | category | 文字 | 「所選項目」 |
   | note | 文字 | 第 4 步的「提供的輸入」 |
   | lat | 數字 | 「目前位置」→ 點它 → 選「緯度」 |
   | lng | 數字 | 「目前位置」→ 點它 → 選「經度」 |

   兩個「提供的輸入」容易選錯：選變數時，直接點畫面上那個動作的輸出（金額那一步／一句話那一步）。
7. **顯示通知**（Show Notification）：內容放「URL 的內容」

**成功時**：執行後跳出通知「已記下支出 120 元」；打開記帳日記（同步後）時間軸出現這筆，地名會自動補上。

- 金額留空、只寫一句話 → 記成日記；金額填 0 → 記成 0 元的帳。
- 想用捷徑記收入：在第 2 步的列表多加「薪水」「獎金」「投資」「退款」，選到這些就會記成收入。
- 外幣：捷徑一律記成新台幣，出國時建議直接在 App 裡記。

加到主畫面：在捷徑上長按 →「分享」→「加入主畫面」。也可以在「控制中心」加入捷徑按鈕。

### C2. 每晚記步數

新捷徑，名稱「記步數」：

1. **尋找健康樣本**（Find Health Samples）：類型「步數」，加入條件「開始日期」「是今天」
2. **計算統計資料**（Calculate Statistics）：「總和」，輸入選上一步的「健康樣本」
3. **取得 URL 內容**：用「步數網址」，JSON 欄位：`steps`（數字）＝「統計資料」
4. **顯示通知**：內容放「URL 的內容」

先手動按一次執行，第一次會問要不要讓捷徑讀取健康資料 → 允許。

**成功時**：通知「已記下 2026-11-18 步數 8231」，記帳日記那天顯示「步數 8,231」。

接著設定每天自動執行：捷徑 App →「自動化」分頁 →「＋」→「特定時間」→ 23:55、每天 →「立即執行」→ 選「記步數」。

注意：手機鎖定時 iPhone 不讓捷徑讀健康資料，可能送出 0 或失敗。伺服器只會記「比較多的那個數字」，送 0 不會蓋掉。如果常常漏記，再加一個你通常還在用手機的時間（例如 22:00）。

### C3. 記下位置（備援，可不做）

背景定位（B）已經會持續記錄，這個只是備援。新捷徑「記下位置」：

1. **取得目前位置**
2. **取得 URL 內容**：用「記下位置網址」，JSON 欄位 `lat`（數字）＝目前位置的緯度、`lng`（數字）＝經度

原本規劃「每小時自動送一次」，但 iOS 捷徑的「特定時間」自動化只能選每天／每週／每月，**沒有每小時**。需要的話就建立幾個不同時間的自動化（例如 9:00、13:00、18:00、22:00），都選「立即執行」→「記下位置」。

## D. 主畫面小工具（Scriptable）

1. App Store 安裝「Scriptable」（免費）。
2. 記帳日記「自動化」→ 展開「⑤ 主畫面小工具」→ 填每月預算（不需要就留空）→ 按「複製 Scriptable 腳本」。
3. 打開 Scriptable → 右上「＋」→ 在空白處長按 →「貼上」→ 上方標題改成「記帳日記」→ 按「完成」。
4. 點這個腳本執行一次。

**成功時**：跳出中型小工具的預覽，有今日支出、本月預算、今天路線。

加到主畫面：
1. 主畫面空白處長按 → 左上「編輯」→「加入小工具」→ 找「Scriptable」→ 選中型 →「加入小工具」。
2. 長按剛加的小工具 →「編輯小工具」→ Script 選「記帳日記」。
3. 想要「一年前的今天」：再加一個小型的，Script 選「記帳日記」，Parameter 填 `一年前`。
4. 鎖定畫面也可以加（長方形那種），顯示今日支出與本月預算。

點小工具會執行捷徑「打開記帳日記」來打開主畫面上的 App：要先建立這個捷徑（一個動作「打開 URL」，網址 `webapp://d22967106-sudo.github.io/App/`），名稱要一字不差。這是 Apple 沒寫在文件裡的做法。

改了預算或重新產生金鑰：重新複製腳本，在 Scriptable 裡把舊內容全選刪掉再貼上。
